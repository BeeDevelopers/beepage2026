# Catálogo verificable de beneficios estudiantiles — Universidad de Guanajuato
> **Corte de investigación: 18 de noviembre de 2026.** 185 registros de servicios, ofertas, accesos y descuentos en 8 bloques temáticos. No es posible garantizar «absolutamente todas» las promociones del mercado: cambian cada día, y muchas requieren sesión o verificación personal. **Ninguna oferta externa ha sido canjeada con una cuenta real `@ugto.mx`**. Cada fila incluye un enlace público para comprobar la afirmación.
## Cómo leer y publicar este catálogo
- **UG-CONFIRMADO:** publicado por la propia Universidad de Guanajuato; aun así, puede requerir asignación de licencia, pertenecer a cierto campus o tener una convocatoria concreta.
- **OFICIAL-ESTUDIANTES:** la empresa ofrece un plan para estudiantes, pero **no se validó que el dominio UG sea aceptado** ni que aplique exactamente la misma oferta a cada estudiante mexicano.
- **PROVEEDOR-MX:** descuentos publicados específicamente en la web mexicana de una marca.
- **GITHUB-PACK:** una oferta anunciada en el catálogo oficial de GitHub Education; requiere cuenta estudiantil verificada y condiciones del socio.
- **MARKETPLACE-POR-VALIDAR:** catálogo mexicano de Student Beans, no comprobación de canje ni garantía de disponibilidad regional.
- **CREDENCIAL-ESTUDIANTE:** se acredita con credencial física/digital, no solo con el correo.
**Regla editorial clave:** no convertir «anunciado», «sujeto a verificación» o «histórico» en una insignia «Disponible para todos». Nunca usar precios o descuentos sin fecha de revisión ni prometer gratuidad automática. La fuente debe ser visible desde cada tarjeta.

### Recomendaciones de implementación para Codex

1. Mantener los datos fuera del JSX, por ejemplo en `src/data/beneficios.ts` o JSON versionado, preservando enlaces de fuentes y `ultimaRevision`.
2. UI consistente con el sitio BeeDevelopers: azul marino, amarillo, encabezado existente, patrón de panal y tipografía actual. Preferir tarjetas con búsqueda y filtros por categoría, tipo y estado.
3. Mostrar **"Publicado por la UG"** solo en registros `ug_confirmado`, **"Oferta para estudiantes"** en proveedores y **"Por confirmar con UG"** en Marketplace. Evitar insignia "Verificado" si nadie canjeó la oferta.
4. Poner botón **"Ver condiciones / fuente"** en toda ficha. `urlActivacion` opcional; cuando falte, enlazar a la fuente.
5. Incorporar una página de detalle con: resumen, quién puede usarlo, cómo verificar, vigencia, restricciones, enlace oficial, fecha de revisión y nota de no afiliación.
6. Promociones de duración limitada deben tener aviso y fecha de expiración. Nunca activar cobros ni solicitar datos de pago desde la web del grupo: remitir al proveedor oficial.
7. En móviles reemplazar tabla por tarjetas y barra lateral por filtros desplazables o acordeón. Añadir buscador de texto y filtro `Sólo confirmados por UG`.
8. No copiar logotipos de marcas sin comprobar uso autorizado; como alternativa usar iconos genéricos. Habilitar revisión editorial antes de publicar.
9. Para Google, Spotify, Samsung y marketplace, no renderizar un precio específico si no hay actualización del día.
10. La sección GitHub Pack agrupa **ofertas de socios**; su inclusión no significa que UG sea socio ni que haya acceso directo con correo sin pasar por GitHub Education.
